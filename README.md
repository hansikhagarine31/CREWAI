# CrewAI Multi-Agent Projects Backend

A production-grade Python FastAPI backend implementing 10 CrewAI projects powered by Google Gemini (`gemini-3.1-flash-lite`).

This repository contains only the three canonical assignment files:
- `app.py`: FastAPI server implementing routes `/agent1` through `/agent10`.
- `requirements.txt`: Python package dependencies.
- `README.md`: Documentation and execution instructions.

---

## The 10 CrewAI Agents

| Route | Project Name | CrewAI Pattern | Description |
|---|---|---|---|
| `POST /agent1` | **Blog Post Crew** | Sequential Crew | Researches topic via DuckDuckGo, drafts a 600-word post, and edits for clarity and tone. |
| `POST /agent2` | **Competitor Analysis Crew** | Hierarchical Crew | Uses a manager agent to coordinate scrapers and analysts, producing a SWOT analysis table. |
| `POST /agent3` | **Meeting Notes Crew** | Parallel Tasks | Runs summarizer, action item extractor, and decision logger concurrently, formatted by a final agent. |
| `POST /agent4` | **Data Report Crew** | Structured Output | Extracts Pydantic metrics from numerical data and writes verified executive summaries. |
| `POST /agent5` | **Customer Support Flow** | Router Flow | Categorizes customer inquiries and routes billing, access, or technical requests dynamically. |
| `POST /agent6` | **Resume Screening Flow** | Router Flow | Screens candidate resumes against job criteria, routing scores ≥ 7 to summary crew and < 7 to rejection email generator. |
| `POST /agent7` | **Bug Triage Flow** | Router + Crews | Classifies issues into bugs, features, or questions, and assigns them to specialized response crews. |
| `POST /agent8` | **Content Repurposing Flow** | `and_` Join Flow | Extracts insights and simultaneously drafts LinkedIn posts, Twitter threads, and newsletters. |
| `POST /agent9` | **Lead Qualification Flow** | Router + Crews | Enriches company domain info and scores leads into Hot (outreach crew), Warm (nurture), or Cold (archive). |
| `POST /agent10` | **Approval Report Flow** | Human Feedback Flow | Conducts in-depth research, drafts a report, and accommodates human review and iterative revisions. |

## API Specification

Every agent endpoint is accessed via HTTP **POST**:

* **Request Format**:
  * **Header**: `Content-Type: application/json`
  * **Body**:
    ```json
    {
      "input": "Your query or input text here"
    }
    ```

* **Response Format**:
  * **Status**: `200 OK`
  * **Body**:
    ```json
    {
      "output": "Result generated by the CrewAI agent..."
    }
    ```

## Local Setup & Execution

### 1. Create a Virtual Environment

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure Environment Variables

Create a `.env` file in this directory:

```env
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.1-flash-lite
PORT=8000
```

### 4. Run the Server

```bash
uvicorn app:app --reload --port 8000
```

The service is available at `http://localhost:8000`.

## Deployment (Render)

1. Create a new **Web Service** on [Render](https://render.com).
2. Connect your GitHub repository.
3. Configure the service:
   - **Environment**: Python
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app:app --host 0.0.0.0 --port $PORT`
4. Add Environment Variables:
   - `GEMINI_API_KEY`: Your Google AI Studio API key.
   - `GEMINI_MODEL`: `gemini-3.1-flash-lite`
5. Note the deployed URL (e.g. `https://your-service.onrender.com`).
